How it works — name-based inference

A simple client-side function checks the student's first name against a list of ~100 common Pakistani girl/boy names. If no match, falls back to a neutral violet theme.

This is purely cosmetic — it only affects the row color + emoji. No gender data is stored or sent to any API.

What each theme includes:

Girl 🩷Row bg: pink-50→pink-100 gradient, border: pink-200, avatar: pink gradient + 👧 emoji, name: pink-900, hover glow: pink
Boy 🩵Row bg: sky-50→sky-100 gradient, border: sky-200, avatar: sky gradient + 👦 emoji, name: sky-900, hover glow: sky
Neutral 💜Row bg: violet-50 gradient (current design), border: violet-200, avatar: violet gradient + first initial, name: slate-900
