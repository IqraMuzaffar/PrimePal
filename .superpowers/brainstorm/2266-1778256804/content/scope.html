Core issues I'm seeing in the screenshot:

  • Container too narrow: home content is capped at max-w-2xl (~672px) inside a max-w-5xl shell — huge empty side bands on desktop.
  • Type too small for kids: "Hi Horain!" is only 24-30px — children's apps usually go 36-48px for primary headings.
  • Visual hierarchy is flat: hero, cards, badges, footer all feel similar in weight.
  • Empty zones: "0 Stars" + "No badges yet" + a generic quote takes up lots of pixels with little payoff.
