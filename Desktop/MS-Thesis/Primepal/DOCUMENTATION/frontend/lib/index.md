# Frontend Libraries

Shared utilities and auth helpers in `frontend/lib/`.

## Modules

| File | Description |
|------|-------------|
| [api.md](api.md) | `apiFetch` — typed fetch wrapper for backend API calls |
| [auth.md](auth.md) | Auth helpers: teacher, student, and admin auth utilities |
| `supabase/client.ts` | Browser-side Supabase client instance |
| `use-sound.ts` | React hook for playing sound effects |
| `avatarHelper.ts` | Avatar URL generation with DiceBear + fallback to `/avatars/default.svg` |
