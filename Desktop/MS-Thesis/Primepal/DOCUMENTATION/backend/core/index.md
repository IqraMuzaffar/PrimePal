# Backend Core Modules

Core modules provide shared infrastructure used across all endpoints.

## Modules

| File | Description |
|------|-------------|
| [config.md](config.md) | Application settings via pydantic-settings (.env) |
| [security.md](security.md) | JWT creation/validation for teachers and students |
| [supabase-client.md](supabase-client.md) | Supabase client factory (anon + service role) |
| [cache.md](cache.md) | Redis initialization and cache helpers |
