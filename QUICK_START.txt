                        PRIMEPAL — QUICK START GUIDE
                              For Windows Users
═══════════════════════════════════════════════════════════════════════════════

STEP 1: INITIAL SETUP (Run Once)
─────────────────────────────────────────────────────────────────────────────

Open PowerShell in project root and run:

  .\SETUP.ps1

This will:
  ✓ Check all dependencies (Python, Node, Docker)
  ✓ Create Python virtual environment
  ✓ Install backend packages (pip install -r requirements.txt)
  ✓ Install frontend packages (npm install)
  ✓ Create .env files

Expected time: 5-10 minutes


STEP 2: CONFIGURE ENVIRONMENT VARIABLES
─────────────────────────────────────────────────────────────────────────────

Edit these files with your actual keys:

  1. backend\.env
     - SUPABASE_URL (from https://app.supabase.com)
     - SUPABASE_ANON_KEY (from Supabase)
     - SUPABASE_SERVICE_ROLE_KEY (from Supabase)
     - OPENAI_API_KEY (from https://platform.openai.com)

  2. frontend\.env.local
     - NEXT_PUBLIC_API_URL=http://localhost:8000/api/v1
     - NEXT_PUBLIC_SUPABASE_URL (from Supabase)
     - NEXT_PUBLIC_SUPABASE_ANON_KEY (from Supabase)


STEP 3: START REDIS (Optional but Recommended)
─────────────────────────────────────────────────────────────────────────────

Open Terminal 0 and run:

  docker-compose up -d

Docker must be running! Start Docker Desktop if not already running.


STEP 4: START BACKEND API
─────────────────────────────────────────────────────────────────────────────

Open Terminal 1 and run:

  .\backend\venv\Scripts\Activate.ps1
  cd backend
  uvicorn app.main:app --reload

Expected output:
  INFO:     Uvicorn running on http://0.0.0.0:8000
  INFO:     Application startup complete

API is ready at: http://localhost:8000


STEP 5: START FRONTEND
─────────────────────────────────────────────────────────────────────────────

Open Terminal 2 (NEW window!) and run:

  cd frontend
  npm run dev

Expected output:
  > next dev
  - ready started server on 0.0.0.0:3000

Frontend is ready at: http://localhost:3000


STEP 6: VERIFY EVERYTHING WORKS
─────────────────────────────────────────────────────────────────────────────

In a browser:
  ✓ http://localhost:3000          (Frontend - landing page)
  ✓ http://localhost:8000/docs     (API docs - Swagger UI)
  ✓ http://localhost:8000/api/v1/topics?grade_level=3  (API test)

You should see:
  - Frontend: PrimePal landing page
  - API Docs: Full interactive documentation
  - API Test: JSON response with topics

COMMON ISSUES
─────────────────────────────────────────────────────────────────────────────

Port 3000/8000 in use?
  → Kill process: netstat -ano | findstr :3000
  → Then: taskkill /PID <PID>
  → Or use different port: uvicorn app.main:app --port 8001

Module not found?
  → Run SETUP.ps1 again
  → Activate venv: .\backend\venv\Scripts\Activate.ps1

Connection refused?
  → Make sure both Terminal 1 & 2 are running
  → Check no errors in terminal output

Blank page in browser?
  → Press F12 to see console errors
  → Check that NEXT_PUBLIC_API_URL is set in frontend\.env.local
